# 會考作文 · 手寫評分

上傳手寫作文照片，AI 會辨識手寫文字，再依**國中教育會考寫作測驗六級分規準**評閱。

## 功能

- 上傳 1–6 張作文照片（依頁序），會先在瀏覽器裡縮圖
- AI 逐字轉錄手寫文字，原本的錯別字與標點照樣保留；辨識結果可以手動修正
- 依會考規準給 0–6 級分，結果包含：
  - 四向度評析：立意取材、結構組織、遣詞造句、錯別字格式與標點符號
  - 優點與待改進
  - 錯別字與標點訂正表
  - 句子改寫示範
  - 「邁向下一級分」的具體建議
- 一鍵複製評語
- 內建評分規準說明（0–6 級分完整描述）

## 使用方式

整個程式只有一個 `index.html`，不需要後端。

- **線上使用**：開啟本 repo 的 GitHub Pages 網址。
- **本機使用**：直接用瀏覽器打開 `index.html`。

在 Claude 以外的地方使用時，需要輸入自己的 [Anthropic API 金鑰](https://console.anthropic.com/settings/keys)。金鑰只會從你的瀏覽器直接送到 Anthropic API。勾選「記住金鑰」時才會存進瀏覽器的 localStorage，公用電腦請不要勾選。

在 Claude 的 Artifact 裡開啟時，會自動改用 Claude 平台內建的 AI，不需要金鑰。

## 注意事項

本工具的評分結果僅供寫作練習參考。正式會考由兩位以上閱卷委員獨立評分。手寫辨識可能出錯，評分前請先核對辨識出的文字。
